Как напарнику запускать этот эксперимент:Твоему напарнику, который отвечает за инфраструктуру, нужно будет выполнить всего одну команду в терминале (предварительно запустив бэкенд через docker-compose up):

Bashlocust -f load\_testing/locustfile.py --headless -u 200 -r 10 --run-time 15m --host http://localhost:8000 --csv=load\_testing/raw\_data/experiment\_1



Что здесь происходит (для понимания физики эксперимента):

\--headless: Запуск без веб-интерфейса, чисто для генерации данных.-u 200 -r 10: Разгон до 200 одновременных пользователей (-u), прибавляя по 10 пользователей в секунду (-r). Это создаст нужное давление на очередь соединений.

\--run-time 15m: Тест длится 15 минут (длительность можно менять в зависимости от того, как быстро упадет сервер с лимитом в 512 Мб).

\--csv=...: Самое главное! Locust сам сохранит сырые логи (включая p95, RPS, количество сбоев) в папку raw\_data, откуда ты их потом заберешь скриптами Pandas для своей предиктивной модели.
